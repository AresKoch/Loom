LOOM
A file browser with Claude and git built in.

WHAT YOU NEED
- Windows 10 or 11, 64 bit.
- Claude Code on this PC, signed in with YOUR OWN Claude account.
  See "IF LOOM SAYS CLAUDE CODE IS NOT INSTALLED" below.
  Loom does not come with an account and stores no passwords or keys.
- For the GIT pane: GitHub Desktop or Git for Windows.

HOW TO START
1. Unzip this whole folder somewhere on your own PC (not inside Program Files).
2. Run "Loom.exe".
   Windows may show "Windows protected your PC" because the app is not
   signed. Click "More info", then "Run anyway".
3. Click "Choose folder..." and pick the root folder you want to work in.
   You can change it any time from the button at the top left.
4. If the Claude pane says "not signed in", click SETTINGS at the top,
   then "Sign in to Claude...".

IF LOOM SAYS CLAUDE CODE IS NOT INSTALLED
1. Open PowerShell (press the Windows key, type "powershell", press Enter).
2. Paste this line and press Enter:

       irm https://claude.ai/install.ps1 | iex

   It shows no progress while it downloads. Wait until it says it is done.
3. CLOSE LOOM COMPLETELY AND OPEN IT AGAIN. Loom only looks for Claude Code
   when it starts.
4. In Loom click SETTINGS at the top, then "Sign in to Claude...", and sign
   in with your own Claude account.
Signing in to the Code tab of the Claude desktop app is not always enough.
The line above is the reliable way.

USING IT
- THE BOARD: Loom opens on a board of sticky notes. Double click anywhere to
  drop a note to yourself. Type / in a note to tag a folder, then click the
  tag to jump straight into that folder. The list on the left jumps into any
  project. BOARD at the top (or Ctrl+B) brings the board back. Esc leaves it.
  To skip the board at startup: SETTINGS, "Open where I left off".
- FILES, GIT and CLAUDE at the top are switches. Turn on any two or all three.
  RIGHT CLICK one of them to fill the window with just that pane.
- RIGHT CLICK any folder or file for Open, Cut, Copy, Paste, Rename, Delete,
  New folder, Compress to ZIP file and Properties.
  Drag the bar between two panes to resize. Double click the bar to reset it.
- Files: folders flow left (root) to right (deepest). Rest the mouse on a
  folder to see inside it, or on a file to preview it.
- Claude: it always knows which folder is open and which files are selected,
  so you can say "what do these do" or "what is in this folder".
- MIC (next to SEND) opens Windows voice typing so you can talk instead of
  typing. Same as pressing the Windows key and H. VOICE ON / OFF at the top of
  the Claude pane makes Claude read its replies out loud. Voice and speed are
  under SETTINGS.
- PHONE at the top links this PC to the Claude app on your phone. A console
  window opens; the first time, answer y to its two questions. Then open the
  Code tab in the Claude app and pick the session named "Loom ...". Keep the
  window open and the PC awake while you use it.
- When Claude saves a file, the folders on the way to it pulse in the tree.
  Click the "Writing ..." line in the chat to jump straight to the file.
- Git: tick files, type a summary, Commit. The third button at the top of the
  pane fetches, pulls or pushes. Push always asks first.
- SETTINGS, Theme: seven looks to pick from.
- The keys along the bottom of the window cover everything else.

WHAT CLAUDE IS ALLOWED TO DO (pick in the Claude pane)
- LOOK: read and answer. Changes nothing. This is the default.
- EDIT: can create and change files in your root folder.
- AUTO: can also run commands Claude Code judges safe.

DELETING
- Delete inside your root folder does not destroy anything. It moves the
  item into a ".folder-map-trash" folder in the root, so you can drag it back.
- Delete on a USB drive is permanent. It asks first.

Your chats, settings and chosen root folder stay on your own PC.
Claude usage counts against your own Claude plan.
